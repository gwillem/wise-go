# Wise API Client

A Go client and CLI for the Wise (TransferWise) API.

## Current Status

### Working Features

- Fetch profiles and balances
- Create quotes
- Create recipients (by IBAN)
- Create transfers
- Sandbox simulation (for testing transfer flows)

### API Funding Limitation (EU/UK Business Accounts)

**Due to PSD2 regulations, EU/UK business accounts cannot fund transfers via API using personal tokens.** This is a regulatory requirement, not a technical limitation.

From [Wise documentation](https://docs.wise.com/guides/developer/auth-and-security):

> EU/UK: Due to PSD2, you cannot fund transfers or view balance statements via API with a personal token.

To fund transfers via API, you need:
- OAuth 2.0 with client credentials
- mTLS (mutual TLS) authentication
- Partnership agreement with Wise

**Workaround:** Create transfers via API, then approve/fund them manually in the Wise app or mobile app.

## CLI Usage

```bash
# Set API key
export WISE_KEY=your-api-token

# List profiles and balances
wisepay -list

# List profiles (sandbox)
wisepay -sandbox -list

# Create a transfer
wisepay -profile 123456 -amount 100 -iban DE89370400440532013000 -name "John Doe"

# Create a transfer with custom currencies and reference
wisepay -profile 123456 -amount 100 -source EUR -target GBP \
        -iban GB82WEST12345698765432 -name "Jane Doe" -ref "Invoice 456"
```

### CLI Options

```
  -sandbox     Use sandbox API
  -list        List profiles and balances
  -profile     Profile ID (required for transfers)
  -amount      Amount to send (required for transfers)
  -source      Source currency (default: EUR)
  -target      Target currency (default: EUR)
  -iban        Recipient IBAN (required for transfers)
  -name        Recipient name (required for transfers)
  -ref         Transfer reference (default: Payment)
```

## Library Usage

```go
package main

import (
    "fmt"
    "wise/pkg/wise"
)

func main() {
    client := wise.NewClient("your-api-token")

    // Get profiles
    profiles, _ := client.GetProfiles()

    // Create a transfer
    result, err := client.CreateTransfer(wise.TransferRequest{
        ProfileID:      profiles[0].ID,
        SourceCurrency: "EUR",
        TargetCurrency: "EUR",
        Amount:         100.00,
        RecipientName:  "John Doe",
        IBAN:           "DE89370400440532013000",
        Reference:      "Invoice 123",
    })
    if err != nil {
        panic(err)
    }

    fmt.Printf("Transfer created: %d (approve in Wise app)\n", result.Transfer.ID)
}
```

## API Documentation

The [docs/api-reference](./docs/api-reference) directory contains the Wise API documentation in Markdown format, generated by `gendocs`. This is useful for LLMs to understand the Wise API without needing web access.

## Sandbox Testing

The `cmd/testfund` tool demonstrates the full transfer flow using sandbox simulation:

```bash
go run ./cmd/testfund
```

This creates a transfer and uses Wise's simulation endpoints to move it through all stages (processing → funds_converted → outgoing_payment_sent), bypassing SCA requirements.

## SCA Implementation Notes

The `pkg/wise/sca.go` file contains a complete SCA implementation using the SIGNATURE challenge:

1. Make request to protected endpoint
2. Receive 403 with `X-2fa-Approval` header containing OTT
3. Sign the OTT: `sha256(ott) -> rsa_sign -> base64`
4. Retry with `X-2fa-Approval: <ott>` and `X-Signature: <signature>`

This implementation is cryptographically correct (verified against [reference implementations](https://rjevski.io/2fastrong-customer-authentication-for-the-wise-api-in-python/)), but **cannot be used with personal tokens for EU/UK business accounts** due to PSD2 regulations.
